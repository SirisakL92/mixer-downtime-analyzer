MIXER PRODUCTION LOG · CLIENT-SIDE ANALYSIS

วิเคราะห์สาเหตุการหยุดเครื่องและพลังงานที่สูญเสีย จากบันทึกการผลิตของคุณเอง

นำเข้าไฟล์บันทึกการผลิตรายวัน (.xlsx) และไฟล์มิเตอร์ไฟฟ้า (.csv) ในรูปแบบเดียวกับที่โรงงานใช้อยู่ — เครื่องมือนี้ประมวลผลทั้งหมดในเบราว์เซอร์ของคุณ ไม่มีข้อมูลถูกส่งออกไปที่เซิร์ฟเวอร์ใดๆ จึงใช้งานได้ปลอดภัยบน GitHub Pages หรือเปิดจากเครื่องโดยตรง

Input .xlsx (DATE / NAME / BATCH / Total Quantity / หมายเหตุ) Input .csv หรือ .xlsx (Timestamp / P-Total / Month-kWH) Runtime 100% client-side · no backend
